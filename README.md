# Orbit Labs

A fast, responsive one-page website built with plain HTML, CSS, and JavaScript.

## What's inside

- Sticky header with a mobile menu
- Animated orbit hero artwork
- Scroll-triggered reveals and number counters
- Responsive work grid and process steps
- Respects `prefers-reduced-motion`

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.
